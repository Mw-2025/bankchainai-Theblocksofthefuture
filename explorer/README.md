# BKC Explorer

Solana-style cluster explorer for Bank Coin (BKC) and Bank Tokens (BKCX).

Live UI: dashboard slug `bkc-explorer` at `/workspace/artifacts/bkc-explorer`.

It starts the BKC chain from this repository, indexes every block into `platform_events` + `banking_ledger`, and links activity to GitHub [`bankchainai/BankchainAI-TheBlocksofthefuture`](https://github.com/bankchainai/BankchainAI-TheBlocksofthefuture).
